# ECE128Lab2Code

This repository contain Verilog code for the design of an 1 bit Full adder and 4 bit full adders. It is meant for lab 2 for ECE128. It contains a 4 bit Ripple Carry Adder and 4 bit Carry Look ahead adder.

Instructions:

Create project in Vivaldo using correct FPGA selected
Move FA code into source file
Assign inputs to switches on FPGA and outputs to LEDs usings provided file
Add constraint to add test bench in
Run Simulation to check wave form (Test bench should show appropriate addition in hexadecimal)
Run synthesis and check resulting gate level results
Create bit stream
Program FPGA
Test FPGA if all test cases work (Example test case: A = 3 (0011) and B = 5(0101) with C_in = 0 should result in Sum = (1000))
